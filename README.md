# Tyumex Smart DNS для Android

[Скачать подписанный APK](https://github.com/Tyumex/tyumex-smart-dns/releases/latest/download/Tyumex-Smart-DNS.apk) · [Выпуски и SHA-256](https://github.com/Tyumex/tyumex-smart-dns/releases)

Android 8.0 и новее. Установите APK, откройте приложение, нажмите «Включить DNS» и подтвердите системный запрос VPN. Чтобы добавить плитку, откройте редактирование быстрых настроек Android. В одном профиле одновременно работает один VPN.

Авторежим сравнивает доступность выбранных доменов по HTTPS с обычной проверкой сертификатов. Выбирает провайдера по количеству успешных проверок, затем по задержке. Это оценка публичной страницы: доступ к аккаунту, API и функциям внутри сайта может отличаться. При смене сети и примерно раз в 15 минут активная служба повторяет проверку. Xbox доступен в ручном режиме. После отключения Android возвращается к DNS сети.

Через локальный виртуальный интерфейс проходят запросы к двум служебным DNS-адресам. Пользовательский стек gVisor обслуживает UDP и TCP, DNS-запросы направляются провайдерам по обычному порту 53. Содержимое остального трафика приложение не обрабатывает. Для выбранных доменов сам Smart DNS может направить соединение через инфраструктуру своего оператора. Шифрование пользовательского DNS этим режимом не предоставляется. Приложения со своим DoH могут обойти выбранный сервер.

## Обновления

Каталог в `catalog/` содержит адреса, ревизию и ссылку на версию исходного проекта. После проверки RSA-подписи новая ревизия заменяет предыдущую целиком. На случай отсутствия сети в APK есть начальный подписанный каталог. Проверка при запуске, вручную и по фоновому расписанию Android. Кнопка обновления скачивает APK, сверяет SHA-256, подпись с установленной копией и номер версии, затем открывает системный установщик Android. Подтвердите установку и при первом обновлении разрешите этому приложению установку из данного источника.

Исходные сведения о DNS: [HB AI Smart DNS 1.25](https://github.com/neiroseti-ai/hb-ai-xbox-dns/releases/tag/v1.25). Android-реализация самостоятельная. Подробности лицензий в NOTICE.md.

## Сборка

См. .github/workflows/build.yml: Go, Android NDK, JDK 17, Gradle 8.11.1, Android SDK 35. Движок поставляется для arm64-v8a, armeabi-v7a и x86_64. Выпуск подписывает отдельный ключ Android. Открытый ключ каталога встроен в APK. Для разработки используйте собственную подпись APK и собственный тестовый каталог.

Проверка сети: engine/main_test.go и tools/emulator-check.py. Сторонние DNS работают по-разному у разных операторов. Обязательна проверка на своей сети.
